# Prototype PWA - Plateforme collaborative marketing (Sport 2000 / Céraclès)

Prototype interactif présenté par **Manica Labs** dans le cadre de la réponse à l'appel d'offres
« Plateforme collaborative marketing » (remplacement d'OPECOM). Écrans non contractuels.

## Contenu

- `index.html` : application autonome (tableau de bord, commande, personnalisation, suivi de projet)
- `manifest.webmanifest` : manifeste PWA (installable, raccourcis Commander / Personnaliser)
- `sw.js` : service worker (app shell en cache, fonctionnement hors ligne)
- `icons/` : icônes de l'application

## Essayer

Ouvrir l'URL GitHub Pages du dépôt sur un smartphone : le navigateur propose l'installation
(Android / Chrome / Edge : bouton « Installer l'application » ; iOS : Partager > Sur l'écran d'accueil).

## Publication (GitHub Pages)

Settings > Pages > Source : *Deploy from a branch* > branche `main`, dossier `/ (root)`.
